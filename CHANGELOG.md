## [0.1.0] - 2026-07-16

### Added

- Recursive, case-insensitive text search with file paths and line numbers
- Configurable context lines and highlighted terminal output
- Default and user-defined ignored directories
- File extension filtering and maximum file-size handling
- Binary, oversized, unreadable, and invalid-input error handling
- Case-sensitive and regular-expression search modes
- JSON output with results and skipped-file summaries
- Vim, Visual Studio Code, and Antigravity editor integration
- Interactive result selection when multiple matches are found
- Automated Ruff, mypy, pytest, package-build, and metadata checks in CI
- Reproducible 1,000-file and 10,000-file scanner benchmarks
- Wheel and source-distribution packaging with MIT licensing
