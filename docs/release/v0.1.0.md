# CodeFind CLI v0.1.0

CodeFind CLI v0.1.0 is the first public release of the terminal code and text search tool.

## Highlights

- Recursive project search with readable context and highlighted matches
- Extension, ignore-directory, context, and maximum-file-size controls
- Case-sensitive and regular-expression search
- JSON output for automation
- Vim, Visual Studio Code, and Antigravity integration
- Graceful handling of binary, oversized, and unreadable files
- Automated quality, package, and metadata validation

## Installation

Install the tagged release with pipx:

```bash
pipx install "git+https://github.com/wewewii/codefide-cli.git@v0.1.0"
codefind --help
```

Alternatively, download the wheel attached to the GitHub release and install it with:

```bash
pipx install codefind_cli-0.1.0-py3-none-any.whl
```

CodeFind requires Python 3.11 or newer.
