# Phase 3 Task Breakdown - Editor and Advanced Search

## Goal
ทำให้ค้นหาแล้วไปแก้ไขต่อได้เร็วขึ้น

## Tasks

เปิดไฟล์ด้วย `vim +line file`

### CF-202 Add `--open code`
เปิดไฟล์ด้วย `code -g file:line`

### CF-203 Add `--open antigravity`
เปิดไฟล์ด้วย `antigravity file`

### CF-204 Result Selection Prompt

### CF-205 Add `--case-sensitive`

### CF-206 Add `--regex`
ค้นหาด้วย regex

### CF-207 Add `--json`
export results เป็น JSON เพื่อรองรับ automation ในอนาคต
